Yoe Yar POS — Windows

1. Right-click the zip file > Extract All.
2. Open the extracted folder and double-click "Install Yoe Yar POS".
   If Windows shows "Windows protected your PC", click "More info" > "Run anyway".
3. Yoe Yar POS opens. Type the shop code you received, with the internet on.
To update later: do the same with the new zip. Your sales and debts are kept.
